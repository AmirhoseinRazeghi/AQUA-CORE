# Changelog

## 1.0.0 — Initial portfolio implementation

- Browser-only static HMI and process simulation.
- Shared tag database, instrumentation quality layer and fixed-step SoftPLC scan engine.
- Structured Text subset parser/interpreter and sample intake control program.
- PID controllers, timer/trigger/counter/latch function blocks and process sequences.
- Water treatment, pumping, filtration, dosing proxy and bottle packaging cell models.
- Alarm/event management and in-memory historian with CSV export.
- Modbus register model, MBAP codec and OPC UA-shaped information model.
- Native WebGL 1 digital twin with Canvas 2D fallback, fault injection lab and automated test bench.
- GitHub Pages deployment workflow and engineering documentation.
