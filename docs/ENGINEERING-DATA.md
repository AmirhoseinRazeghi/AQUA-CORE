# Engineering Data Index

The machine-readable engineering data files are:

- [`IO-LIST.csv`](IO-LIST.csv) — source-of-truth tag definitions exported from `config/tag-database.js`.
- [`INSTRUMENT-INDEX.csv`](INSTRUMENT-INDEX.csv) — AI/DI instrument and field-status index.
- [`MODBUS-REGISTER-MAP.csv`](MODBUS-REGISTER-MAP.csv) — holding/input/coils/discrete map.
- [`CAUSE-AND-EFFECT.csv`](CAUSE-AND-EFFECT.csv) — summarized cause/effect relationships.

The CSV files are engineering documentation for the simulator. They are not an issued-for-construction I/O schedule or an approved control-system database.
